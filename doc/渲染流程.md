当前完整流程分析
---
1. 主线程 — view_example.cpp
① 创建窗口: PlatformWindow::Create("Kwik UI - Vulkan", 800, 600)
   → Win32: CreateWindowEx(..., 800, 600)
   → GetSize() 返回 {800, 600}
② 启动渲染线程: RenderThread(config{BackendType::Vulkan, 800, 600})
   → 新线程 threadMain() → initBackend() → VulkanBackend::initialize(HWND, 800, 600)
   → initVulkan() → Instance → Surface → Device → createSwapchain() → Pipeline → Buffers → Sync
③ JS → C++ 解析: ElementParser::parse() → 返回 View 树
④ 布局: tree->measure(Constraints::loose({800, 600}))
        tree->layout(Rect(0, 0, 800, 600))
   → 根 View frame={0,0,800,600} padding=20
   → 子 View 1 frame={20,20,200,100}   ← 绿色
   → 子 View 2 frame={20,120,200,100}  ← 蓝色
   → 子 View 3 frame={20,220,200,100}  ← 橙色
⑤ 渲染循环 (每帧):
   PollEvents()
   cmdBuffer = commandQueue.currentBuffer()
   Graphics canvas(&cmdBuffer)
   canvas.beginFrame()          → 记录 BeginFrameCmd
   canvas.clear({255,255,255})  → 记录 ClearCmd{white}
   tree->draw(canvas)           → 记录 FillRoundedRectCmd / StrokeRoundedRectCmd / DrawShadowCmd…
                                 （rect 坐标基于 frame，即屏幕像素坐标 (0,0)~(800,600)）
   canvas.endFrame()            → 记录 EndFrameCmd
   commandQueue.submit()        → 推入队列，notify 渲染线程
2. Graphics 录制层
View::onDraw(frame)
  ├─ save() / restore()           → SaveStateCmd / RestoreStateCmd
  ├─ setOpacity(opacity)          → SetOpacityCmd
  ├─ drawShadow(frame, r, shadow) → DrawShadowCmd{rect=frame}
  ├─ drawRoundedRect(frame, r, bg)→ FillRoundedRectCmd{rect=frame}
  ├─ drawRoundedRectStroke(frame, r, color, w) → StrokeRoundedRectCmd{rect=frame}
  ├─ clipRoundedRect(contentRect) → ClipRoundedRectCmd (空实现)
  └─ 递归 child->draw(graphics)
> 注意: Graphics::drawRoundedRect() 调用 transformRect(rect) 但当前无 translate/scale，所以 rect 原样透传。applyOpacity(color) 乘以当前 opacity 后也透传。
3. CommandQueue — 线程间传递
主线程:                   渲染线程:
currentBuffer()           acquire(true) → 阻塞 cv_.wait()
  ← 写入命令到 buffer[0]     ↓ 被 submit 唤醒
submit()                    pendingBuffer_ = buffer[0]
  → buffer[0] 推入队列      processCommands(pendingBuffer_)
  → cv_.notify_one()        release() → pendingBuffer_ = nullptr
  → 切换到 buffer[1]         ← 回到 acquire(true) 等待下一帧
4. RenderThread — 命令分发
processCommands(buffer)
  ├─ backend_->beginFrame()   ← VulkanBackend
  ├─ for each Command:
  │    executeCommand(cmd)
  │      ├─ ClearCmd         → backend_->clear(color)
  │      ├─ FillRoundedRectCmd→ backend_->fillRoundedRect(rect, radius, color)
  │      ├─ StrokeRoundedRectCmd→ backend_->strokeRoundedRect(...)
  │      ├─ DrawShadowCmd    → backend_->drawShadow(rect, radius, shadow)
  │      └─ SetOpacityCmd    → backend_->setGlobalAlpha(alpha)
  └─ backend_->endFrame()
5. VulkanBackend — 渲染管线
beginFrame():
  vkWaitForFences(inFlightFence_)      ← 等上一帧 GPU 完成
  vkAcquireNextImageKHR → currentImageIndex_
  vkResetCommandBuffer(cmd[currentImageIndex_])
  vkBeginCommandBuffer(...)
  vkCmdBeginRenderPass(loadOp=DONT_CARE)   ← 不清屏，附件内容未定义
  vkCmdSetViewport(0, 0, swapchainExtent_)  ← 视口 = swapchain 尺寸
  vkCmdSetScissor(swapchainExtent_)
clear(color):
  vkCmdClearAttachments(color)          ← 全屏清为白色
fillRoundedRect(rect, radius, color):
  vkCmdBindPipeline(fillPipeline_)
  PushConstants{ topLeft=rect.xy, size=rect.wh, fillColor=(R,G,B,A),  ← 注意：颜色 RGB 顺序
                 radius, drawMode=0, viewportW/H=swapchainExtent_ }
  vkCmdPushConstants(...)
  vkCmdDrawIndexed(6)                  ← 绘制一个 quad，shader 负责圆角裁剪
strokeRoundedRect(...):
  vkCmdBindPipeline(strokePipeline_)
  PushConstants{ ... borderWidth, borderColor=(R,G,B,A), drawMode=1 ... }
drawShadow(...):
  vkCmdBindPipeline(shadowPipeline_)
  PushConstants{ topLeft=rect+shadowOffset, fillColor=shadowColor,
                 drawMode=2, shadowOffset, shadowBlur ... }
endFrame():
  vkCmdEndRenderPass()
  vkEndCommandBuffer()
present():
  vkResetFences(inFlightFence_)
  vkQueueSubmit(signal=inFlightFence_, signal=renderFinishedSemaphore_)
  vkQueuePresentKHR(wait=renderFinishedSemaphore_)  → 上屏
6. Shader — NDC 变换链路
顶点着色器 rect.vert:
  screenPos = pc.topLeft + inPosition * pc.size     ← 像素坐标 (0~800, 0~600)
  ndc = screenPos / pc.viewportSize * 2.0 - 1.0    ← 归一化设备坐标
  gl_Position = vec4(ndc, 0, 1)
片段着色器 rect.frag:
  用 fragPos (quad内0~1) 计算 SDF，区分 fill/stroke/shadow 三种模式
  outColor → B8G8R8A8 attachment → 显示



# 文字渲染架构概要
Main Thread                              Render Thread
──────────                               ─────────────
Graphics::drawText(text, font, size, pos, color)
  ├─ FontManager::shapeText()           ──┐
  │    └─ HarfBuzz shape → glyph list      │
  ├─ FontManager::getGlyphInfo()           │  CommandQueue
  │    └─ FreeType SDF raster → atlas      │  (DrawGlyphCmd × N)
  └─ for each glyph:                       │
       CommandBuffer::add(DrawGlyphCmd) ──┘
                                                 └─ VulkanBackend::drawGlyph()
                                                       ├─ bind glyphPipeline_
                                                       ├─ push: pos, UV, color, viewport
                                                       └─ vkCmdDrawIndexed(quad)
SDF 着色器核心逻辑：smoothstep(0.5 - fwidth, 0.5 + fwidth, texture(atlas, uv).r) — 分辨率无关的抗锯齿。
