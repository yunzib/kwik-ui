# 1. 组件说明

KwiK UI 是一个声明式 UI 框架。用户通过 JS 编写 `View(...)` 组件树描述界面，
框架内部使用 C++ 进行 measure/layout/draw 三阶段渲染，支持 SDF 字体、
GPU 纹理、State 响应式状态、增量更新等特性。

组件系统整体结构可划分为组件和属性：组件是功能划分，属性则是组件对应的功能集合。

## 1.1 通用属性
ViewProps 是 View 的基础属性， 所有组件继承以下属性：

```json
{
    // ── 尺寸 ──
    "width": "number | null",          // 固定宽度 (null=自动)
    "height": "number | null",         // 固定高度 (null=自动)

    // ── 显示 ──
    "id": "string",                    // 全局唯一标识
    "background": "#rrggbb",           // 背景色 (默认透明)
    "borderRadius": "number",          // 圆角半径 px (默认 0)
    "borderWidth": "number",           // 边框线宽 px (默认 0)
    "borderColor": "#rrggbb",          // 边框颜色
    "borderStyle": "\"solid\" | \"dashed\" | \"none\"",  // 边框样式
    "padding": "14 | [12,8] | {top,right,bottom,left}",  // 内边距
    "margin": "14 | [12,8] | {top,right,bottom,left}",   // 外边距
    "visible": "boolean",              // 是否可见 (默认 true)
    "opacity": "0.0-1.0",              // 透明度 (默认 1.0)
    "scale": "number",                 // 缩放倍率 (默认 1.0，支持动画)
    "shadow": "\"0 3px 12px rgba(0,0,0,0.4)\" | null",  // 阴影
    "z": "number",                     // 层级优先级 (默认 0，越大越靠前)

    // ── 定位 ──
    "position": "\"relative\" | \"absolute\"",  // 定位模式 (默认 "relative")
    "top": "number",                   // 绝对定位上边距 (-1=自动)
    "left": "number",                  // 绝对定位左边距 (-1=自动)
    "right": "number",                 // 绝对定位右边距 (-1=自动)
    "bottom": "number",                // 绝对定位下边距 (-1=自动)
    "x": "number",                     // 显式 X 偏移
    "y": "number",                     // 显式 Y 偏移
    "align": "string",                 // 子项对齐 (见下方说明，默认 "default")

    // ── Flex 子项 ──
    "flexGrow": "number",              // Flex 放大因子 (默认 0)
    "flex": "number",                  // flexGrow 的别名
    "flexBasis": "number",             // Flex 基准尺寸 (默认 -1)

    // ── Grid 子项 ──
    "gridRow": "number",               // 行索引
    "gridColumn": "number",            // 列索引
    "gridRowSpan": "number",           // 跨行数 (默认 1)
    "gridColumnSpan": "number",        // 跨列数 (默认 1)

    // ── 事件 ──
    "onClick": "(e) => {}",            // 点击回调 e={x,y}
    "onLongPress": "(e) => {}",        // 长按回调
    "onHoverEnter": "() => {}",        // 鼠标进入
    "onHoverLeave": "() => {}",        // 鼠标离开
    "onChange": "(e) => {}"            // 值变更回调
}
```
### 数据类型格式
- EdgeInsets（外边距/内边距）：
```
// 三种格式:
14                                        // 四边相同
[12, 8]                                   // [水平, 垂直]
{ "top": 2, "right": 8, "bottom": 5, "left": 3 }  // 四边分别
```
- Color（颜色）
```
// 十六进制字符串:
"#2196F3"          // RGB
"#F5F5F5CC"        // RGBA
"transparent"       // 透明
```
- Shadow（阴影）
```
// CSS box-shadow 字符串:
"0 3px 12px rgba(0,0,0,0.4)"
//   ↑     ↑        ↑
// offsetX offsetY blurRadius color

```
## 1.2 View — 基础容器
- 最基础的矩形容器，所有组件的父类。支持背景、边框、圆角、阴影、子组件嵌套。
- 专有属性: 无（全部为通用 ViewProps）

## 1.3 Text — 文本显示
基于 SDF（Signed Distance Field）的高清文字组件。支持多字号、颜色、字重，
中文 Unicode 完整支持。文字在任意缩放比例下保持边缘清晰。

```json
{
    "text": "string",                  // 文本内容 (默认 "")
    "fontSize": "number",              // 字号 px (默认 16)
    "color": "#rrggbb",                // 文字颜色 (默认 "#000000")
    "fontWeight": "\"normal\" | \"medium\" | \"bold\"",  // 字重
    "fontStyle": "\"normal\" | \"italic\"",              // 字体样式 (默认 "normal")
    "fontFamily": "string",            // 字体名 (留空用系统默认)
    "textAlign": "\"left\" | \"center\" | \"right\" | \"justify\""  // 对齐方式
}

```

## 1.4 Button — 按钮
交互式按钮组件。支持 hover/press 视觉状态反馈、按压缩放动画、
自动颜色推导。不设背景色时默认 Material Blue 主题。

```json
{
    "text": "string",                  // 按钮文字 (默认 "")
    "fontSize": "number",              // 文字字号 (默认 16)
    "color": "#rrggbb",                // 文字颜色 (默认 "#ffffff")
    "fontWeight": "\"normal\" | \"medium\" | \"bold\"",  // 字重
    "fontFamily": "string",            // 字体名

    // 交互状态
    "hoverBackground": "#rrggbb",      // 悬停背景色 (自动推导)
    "pressedBackground": "#rrggbb",    // 按下背景色 (自动推导)
    "pressedScale": "number",          // 按下缩放 (默认 0.95)
    "hoverBorderColor": "#rrggbb",     // 悬停边框色
    "pressedBorderColor": "#rrggbb",   // 按下边框色
    "hoverShadow": "string | null",    // 悬停阴影
    "pressedShadow": "string | null"   // 按下阴影
}

```

## 1.5 Input — 单行文本输入
单行文本输入框。支持中文 IME 输入、密码遮罩模式 (●)、只读模式、
光标闪烁、键盘导航（Backspace / Delete / 方向键 / Home / End）、
聚焦蓝色边框反馈。

```json
{
    "value": "string",                 // 初始文本 (默认 "")
    "placeholder": "string",           // 占位符 (默认 "")
    "fontSize": "number",              // 字号 px (默认 16)
    "type": "\"text\" | \"password\"", // 输入类型 (默认 "text")
    "readOnly": "boolean",             // 只读模式 (默认 false)
    "maxLength": "number",             // 最大字符数 (0=不限)
    "textColor": "#rrggbb",            // 文字颜色 (默认 "#000000")
    "placeholderColor": "#rrggbb",     // 占位符颜色 (默认 "#999999")
    "cursorColor": "#rrggbb",          // 光标颜色 (默认 "#4285F4")
    "focusedBorderColor": "#rrggbb",   // 聚焦边框色 (默认 "#4285F4")
    "onChange": "(value) => {}"        // 文本变更回调
}
```
## 1.6 TextArea — 多行文本输入
多行文本输入控件。支持 Enter 换行、宽度感知软换行、上下方向键行间导航、
光标闪烁、聚焦边框反馈。非受控模式，通过 getProp/setProp 读写内容。

```json
{
    "value": "string",                 // 初始多行文本 (含 \\n, 默认 "")
    "placeholder": "string",           // 占位符 (默认 "")
    "fontSize": "number",              // 字号 px (默认 16)
    "rows": "number",                  // 可见行数 (默认 4)
    "readOnly": "boolean",             // 只读模式 (默认 false)
    "maxLength": "number",             // 最大字符数 (0=不限)
    "textColor": "#rrggbb",            // 文字颜色 (默认 "#000000")
    "placeholderColor": "#rrggbb",     // 占位符颜色 (默认 "#999999")
    "cursorColor": "#rrggbb",          // 光标颜色 (默认 "#4285F4")
    "focusedBorderColor": "#rrggbb"    // 聚焦边框色 (默认 "#4285F4")
}
```
## 1.7 Checkbox — 复选框
点击切换选中状态，自定义颜色主题，触发 onChange 回调。
可独立使用或配合 State 管理选中状态。

```json
{
    "text": "string",                  // 标签文字 (默认 "")
    "fontSize": "number",              // 标签字号 (默认 16)
    "color": "#rrggbb",                // 标签颜色 (默认 "#000000")
    "fontWeight": "\"normal\" | \"medium\" | \"bold\"",
    "fontFamily": "string",
    "checked": "boolean",              // 选中状态 (默认 false)
    "checkedColor": "#rrggbb",         // 选中边框色 (默认 "#1976D2")
    "checkedFillColor": "#rrggbb",     // 选中填充色 (默认 "#1976D2")
    "checkMarkColor": "#rrggbb",       // ✓ 号颜色 (默认 "#ffffff")
    "uncheckedColor": "#rrggbb",       // 未选中边框色 (默认 "#9E9E9E")
    "boxSize": "number",               // 方框边长 px (默认 20)
    "borderRadius": "number",          // 方框圆角 (默认 4)
    "ringWidth": "number",             // 边框线宽 px (默认 2)
    "textSpacing": "number",           // 方框与文字间距 (默认 8)
    "onChange": "(e) => {}"            // 状态变更回调 e={checked: bool}
}
```
## 1.8 RadioButton — 单选按钮
同组互斥，点击切换选中状态。支持自定义颜色主题、尺寸调节、文字标签。
配合 State 使用 checked 表达式实现动态选中，配合 RadioGroup 实现容器式组管理。

```json
{
    "text": "string",                  // 标签文字 (默认 "")
    "fontSize": "number",              // 标签字号 (默认 16)
    "color": "#rrggbb",                // 标签颜色 (默认 "#000000")
    "fontWeight": "\"normal\" | \"medium\" | \"bold\"",
    "fontFamily": "string",
    "value": "string",                 // 选中对应的值
    "group": "string",                 // 互斥组名
    "checked": "boolean",              // 选中状态 (默认 false)
    "checkedColor": "#rrggbb",         // 选中外圈色 (默认 "#1976D2")
    "uncheckedColor": "#rrggbb",       // 未选中外圈色 (默认 "#9E9E9E")
    "dotColor": "#rrggbb",             // 内圆点色 (默认 "#1976D2")
    "radioSize": "number",             // 外圈直径 px (默认 20)
    "dotSize": "number",               // 内圆点直径 px (默认 12)
    "ringWidth": "number",             // 外圈线宽 px (默认 2)
    "textSpacing": "number",           // 圆圈与文字间距 (默认 8)
    "onChange": "(e) => {}"            // 选中回调 e={checked: bool}
}
```
## 1.9 RadioGroup — 单选按钮组
RadioButton 组管理容器。声明组名和当前选中值，子 RadioButton
仅需声明 value，由 RadioGroup 统一管理互斥状态。
```json
{
    "name": "string",                  // 组名 (匹配子 RadioButton 的 group)
    "selected": "string",              // 当前选中的 value 值
    "onChange": "(e) => {}"            // 选中回调 e={value: string}
}
```
## 1.10 Image — 图片
支持 PNG / JPEG / BMP / GIF / SVG 等格式。
通过 GPU 纹理渲染带圆角裁剪的图片，支持三种缩放策略。
```json
{
    "src": "string",                   // 图片路径 (默认 "")
    "data": "ArrayBuffer",             // 内存像素数据源（与 src 二选一）
    "width": "number",                 // 像素数据宽度（data 模式必需）
    "height": "number",                // 像素数据高度（data 模式必需）
    "fit": "\"contain\" | \"cover\" | \"fill\" | \"none\"",  // 缩放策略 (默认 "cover")
    "opacity": "0.0-1.0"               // 透明度 (默认 1.0)
}
```
## 1.11 Flex — 弹性布局
子项沿主轴方向排列，通过 justifyContent/alignItems 控制对齐，
通过子项的 flexGrow 实现弹性空间分配。
```json
{
    "direction": "\"row\" | \"column\"",          // 主轴方向 (默认 "row")
    "gap": "number",                               // 子项间距 px (默认 0)
    "justifyContent": "\"start\" | \"center\" | \"end\" | \"spaceBetween\" | \"spaceAround\" | \"spaceEvenly\"",
    "alignItems": "\"start\" | \"center\" | \"end\" | \"stretch\""
}
```
## 1.12 Grid — 网格布局
子项通过 gridRow/gridColumn 指定网格位置，支持跨行跨列。
```json
{
    "columns": "number",               // 列数 (默认 1)
    "rows": "number",                  // 行数 (默认 1)
    "columnGap": "number",             // 列间距 px (默认 0)
    "rowGap": "number"                 // 行间距 px (默认 0)
}
```
## 1.13 Stack — 堆叠布局
所有子项在相同 Z 轴层级堆叠，通过 position: "absolute"
配合 top/left/right/bottom 实现任意位置精确定位。

## 1.14 List — 滚动列表
子项沿指定方向堆叠，超出容器尺寸时自动启用滚动。
支持水平和垂直两个滚动方向。
```json
{
    "scrollDirection": "\"vertical\" | \"horizontal\" | \"both\"",  // 滚动方向 (默认 "vertical")
    "gap": "number",                                       // 子项间距 px (默认 0)
    "dividerColor": "#rrggbb",                             // 分割线颜色 (默认透明)
    "dividerHeight": "number",                             // 分割线高度 px (默认 0)
    "header": "View",                                      // 列表头部固定内容 (一个 View)
    "footer": "View"                                       // 列表尾部固定内容 (一个 View)
}
```
## 1.15 Dropdown — 下拉选择
- 下拉选择控件。点击触发区展开菜单，选中项高亮回显，点击外部或选中后自动收起。
- 展开时自动提升 z 层级 (z=100)，确保菜单置顶且事件优先命中。
- 支持滚动 (maxVisibleItems 控制可见窗口，鼠标滚轮浏览溢出项)。
- 通过 getProp/setProp 读写选中值，支持 onChange 回调。

```json
{
    "placeholder": "string",            // 占位符 (未选择时显示, 默认 "请选择...")
    "items": "string[]",                // 选项列表 (默认 [])
    "selectedIndex": "number",          // 选中索引 (-1=未选中, 默认 -1)
    "fontSize": "number",              // 文字字号 px (默认 14)
    "itemHeight": "number",            // 每个选项高度 px (默认 20)
    "maxVisibleItems": "number",       // 同时可见最大选项数 (默认 5)
    "textColor": "#rrggbb",            // 文字颜色 (默认 "#000000")
    "placeholderColor": "#rrggbb",     // 占位符颜色 (默认 "#999999")
    "arrowColor": "#rrggbb",           // 箭头 ▼ 颜色 (默认 "#999999")
    "menuBackground": "#rrggbb",       // 菜单背景色 (默认 "#ffffff")
    "hoverBackground": "#rrggbb",      // 悬停高亮色 (默认 "#E3F2FD")
    "selectedBackground": "#rrggbb",   // 选中项背景色 (默认 "#E3F2FD")
    "onChange": "(e) => {}"            // 选中回调 e={value, index}
}
```

## 1.16 Slider — 滑动条

水平轨道 + 可拖拽圆形滑块。支持鼠标拖拽、键盘方向键、Tap 跳转。
配合 `ref()` 实现双向绑定，支持增量更新拖拽不中断。

```json
{
    "value": "number | ref(form, key)",    // 当前值 / 双向绑定 (默认 0)
    "min": "number",                       // 最小值 (默认 0)
    "max": "number",                       // 最大值 (默认 100)
    "step": "number",                      // 步长 (<=0 连续, 默认 1)
    "color": "#rrggbb",                    // 滑块 + 激活轨道色 (默认 "#1976D2")
    "trackColor": "#rrggbb",              // 未激活轨道色 (默认 "#E0E0E0")
    "thumbSize": "number",                 // 滑块直径 px (默认 20)
    "trackHeight": "number",               // 轨道高度 px (默认 6)
    "onChange": "(e) => {}"                // 拖拽中持续回调 e={value: number}
}
```

## 1.17 ProgressBar — 进度条

水平圆角轨道 + 根据 value 比例填充的激活段。只读组件，无交互（不响应鼠标/触屏/键盘事件）。
配合 `ref()` 实现双向绑定，支持增量更新。

```json
{
    "value": "number | ref(state, key)",  // 当前值 / 双向绑定 (默认 0)
    "min": "number",                       // 最小值 (默认 0)
    "max": "number",                       // 最大值 (默认 100)
    "color": "#rrggbb",                    // 填充段颜色 (默认 "#1976D2")
    "trackColor": "#rrggbb",              // 轨道背景色 (默认 "#E0E0E0")
    "trackHeight": "number",               // 轨道高度 px (默认 6)
    "onChange": "(e) => {}"                // 值变更回调 e={value: number}
}
```
## 1.18 Switch — 切换开关

胶囊形轨道 + 圆形滑块，点击切换 checked 状态。无文字标签（由外部 Flex 组合 Text 实现）。
配合 `ref()` 实现双向绑定，支持增量更新。

```json
{
    "checked": "boolean | ref(state, key)",  // 选中状态 (默认 false)
    "checkedColor": "#rrggbb",              // 选中轨道色 (默认 "#1976D2")
    "uncheckedColor": "#rrggbb",            // 未选中轨道色 (默认 "#E0E0E0")
    "thumbColor": "#rrggbb",                // 滑块颜色 (默认 "#FFFFFF")
    "trackHeight": "number",               // 轨道高度 px (默认 28)
    "thumbSize": "number",                 // 滑块直径 px (默认 20)
    "onChange": "(e) => {}"                // 状态变更回调 e={checked: bool}
}
```
## 1.19 Line — 线段/分割线

水平或垂直线段组件，可自定义粗细和颜色。参与 flex 流式布局，常用作分割线或装饰线。

```json
{
    "direction": "\"horizontal\" | \"vertical\"",  // 方向 (默认 "horizontal")
    "strokeWidth": "number",                       // 线宽 px (默认 1)
    "color": "#rrggbb"                             // 线条颜色 (默认 "#E0E0E0")
}
```

## 1.20 Spinner — 加载指示器

12 圆点沿轨道旋转的加载动画，旋转弧效果。弧段内圆点高亮、其余低亮形成旋转尾迹。
创建后自动持续旋转，无需用户交互。

```json
{
    "color": "#rrggbb",                    // 圆点颜色 (默认 "#1976D2")
    "size": "number",                      // 整体尺寸 px (默认 32)
    "strokeWidth": "number",               // 圆点直径 px (默认 6)
    "trackColor": "#rrggbb",              // 背景圆点颜色 (默认同 color 15% 亮度)
    "arcLength": "number",                 // 弧段角度 0-360 (默认 200)
}
```

## 1.21 TextView — 富文本展示/编辑

基于 TextRun[] 的多行富文本组件。支持行内样式（加粗/下划线/删除线/颜色/字号）、
多行软换行、键盘编辑快捷键，可通过 `value` 与 State 双向绑定。

```json
{
    // ── 内容模式 ──
    "value": "string | ref(state, key)",     // 纯文本，支持 ref 双向绑定
    "content": "TextRun[]",                  // 预置富文本数组 (只读/初始展示)

    // ── 占位符 ──
    "placeholder": "string",                 // 空内容时占位文本 (默认 "")
    "placeholderColor": "#rrggbb",           // 占位符颜色 (默认 "#999999")
    "placeholderFontSize": "number",         // 占位符字号 (默认同编辑区)

    // ── 编辑控制 ──
    "readOnly": "boolean",                   // 只读模式 (默认 false)
    "maxLength": "number",                   // 最大字符数 (0=不限)

    // ── 外观 ──
    "cursorColor": "#rrggbb",               // 光标颜色 (默认 "#4285F4")
    "selectionColor": "#rrggbb",            // 选中背景色 (默认 "#90CAF9")
    "focusedBorderColor": "#rrggbb",        // 聚焦边框色 (默认 "#4285F4")

    // ── 事件 ──
    "onchange": "(content) => {}"            // 内容变更回调，返回完整 TextRun[]
}
```
TextRun 格式
```json
{
    "text": "string",                         // 文本段内容
    "fontSize": "number",                     // 字号 px (默认 16)
    "fontWeight": "\"normal\" | \"bold\"",    // 字重 (默认 "normal")
    "fontStyle": "\"normal\" | \"italic\"",   // 斜体 (默认 "normal"，仅数据层)
    "textColor": "#rrggbb",                   // 文字颜色 (默认 "#000000")
    "underline": "boolean",                   // 下划线 (默认 false)
    "strikethrough": "boolean"                // 删除线 (默认 false)
}
```

### 编辑操作
- Enter: 插入 \n 硬换行
- Soft wrap: 行末 space 处自动截断换行
- 方向键: 逐字符/逐行导航

## 1.22 Table — 数据表格
按 columns 定义渲染表头 + 数据行 + 斑马纹 + grid 边框。
数据由 JS 传入 data 数组，columns 定义列结构。
表头点击不处理排序（由 JS 侧 array.sort() 自行处理）。
```json
{
    "columns": [                              // 列定义数组
        {
            "title": "string",               // 列标题
            "key": "string",                 // 数据字段 key
            "width": "number",               // 固定宽 px (0=auto/flex)
            "flex": "number",                // flex 分配剩余空间比例
            "align": "\"left\" | \"center\" | \"right\""  // 对齐 (默认 "left")
        }
    ],
    "data": "object[]",                     // 数据行数组 [{key: val, ...}, ...]

    // ── 外观 ──
    "headerColor": "#rrggbb",              // 表头背景色 (默认 "#F0F0F0")
    "headerTextColor": "#rrggbb",          // 表头文字色 (默认 "#333333")
    "stripeColor": "#rrggbb",              // 斑马纹色 (默认 "#F5F5F5")
    "rowTextColor": "#rrggbb",             // 行文字色 (默认 "#333333")
    "borderColor": "#rrggbb",              // 边框色 (默认 "#E0E0E0")
    "sortArrowColor": "#rrggbb",           // 排序箭头色 (默认 "#999999")
    "headerHeight": "number",              // 表头高 px (默认 36)
    "rowHeight": "number",                 // 行高 px (默认 32)
    "fontSize": "number",                  // 字号 px (默认 14)
    "borderWidth": "number",               // 边框线宽 px (默认 1)
    "showHeader": "boolean",               // 显示表头 (默认 true)
    "striped": "boolean",                  // 启用斑马纹 (默认 true)
    "fontFamily": "string",                // 字体名

    // ── 事件 ──
    "onRowClick": "(e) => {}"              // 行点击 e={index: number, row: object}
}
```
### 布局策略
- 列宽优先级：width 固定宽 > flex 比例分配 > 等分剩余空间
- 无 width/flex 的列等分剩余空间
- 内容总宽超出可用宽度时溢出（暂无滚动，可配合 ListLayout）
- 行高由 rowHeight 统一控制，不支持自动换行

### 数据流
- data 数组由 JS 侧持有引用，Table 在 C++ 侧通过 getProperty 逐行读取
- 排序由 JS 侧 array.sort() 修改 data 后触发全量重建
- 行点击通过 onRowClick 回调返回 {index, row}，row 为 JS 对象引用

## 1.23 动画系统

KwiK UI 内置 GPU 级动画引擎，支持弹性物理、贝塞尔缓动、关键帧、组合动画。

### JS API

```js
import { animate, stop, isAnimating } from 'kwikui';
```

#### animate(target, props, options)


| 参数 | 类型 | 说明 |
|------|------|------|
| target | string \\| string[] | View id 或 id 数组（数组时启用 stagger） |
| props | object | 属性 → 目标值映射（见下方可动画属性） |
| options.duration | number | 时长（秒，默认 0.3） |
| options.delay | number | 延迟启动（秒，默认 0） |
| options.easing | string \\| number[] | 缓动函数名或 cubic-bezier [p1x,p1y,p2x,p2y] |
| options.loop | number \\| boolean | 循环次数（0/true=无限，默认 1） |
| options.direction | string | "forward" \\| "reverse" \\| "alternate" |
| options.stagger | number | target 为数组时，每项延迟偏移（秒） |
| options.keyframes | number[] | 显式关键帧时间位置 [0, ..., 1] |


返回 Promise<{ completed: boolean }>。


#### stop(target, prop?)


停止 target 上所有动画（不指定 prop）或指定属性的动画。


#### isAnimating(target, prop?)

查询 target 上是否有动画正在运行。

### 可动画属性

| 属性 | 类型 | 插值方式 | 影响布局 |
|------|------|----------|----------|
| opacity | number | 线性插值 | 否 |
| scale | number | 线性插值 | 否 |
| background | #rrggbb | RGBA 逐通道插值 | 否 |
| borderRadius | number | 线性插值 | 否 |
| borderWidth | number | 线性插值 | 否 |
| borderColor | #rrggbb | RGBA 逐通道插值 | 否 |
| textColor | #rrggbb | RGBA 逐通道插值 | 否 |
| fontSize | number | 线性插值 | 否 |
| translateX / translateY | number | 线性插值 | 否 |
| width / height | number | 线性插值 | **是** |
| padding / margin | EdgeInsets | 逐边插值 | **是** |

### 缓动函数

| 名称 | 说明 |
|------|------|
| "linear" | 匀速 |
| "ease" | 平滑减速（默认） |
| "easeIn" | 先慢后快 |
| "easeOut" | 先快后慢 |
| "easeInOut" | 两端慢中间快 |
| "spring(stiffness,damping)" | 弹性物理：stiffness 越高越快，damping 越高回弹越少 |
| [p1x, p1y, p2x, p2y] | 自定义 cubic-bezier 曲线 |

### 关键帧

传入值数组即启用关键帧模式：

```js
// 自动均分时间点 [0, 0.25, 0.5, 0.75, 1]
animate('box', { opacity: [1, 0.2, 1, 0.2, 1] }, { duration: 1.0 });

// 显式时间位置
animate('box', { opacity: [1, 0.2, 1] }, {
    duration: 1.0,
    keyframes: [0, 0.3, 1]
});
```

### 组合动画

同时对多个属性做不同缓动：

```js
animate('box', {
    scale: 1.8,
    borderRadius: 75,
    background: '#67C23A'
}, {
    duration: 0.6,
    easing: 'spring(200,15)'
});
```

### 往返循环

```js
animate('box', { scale: 1.8 }, {
    duration: 0.7,
    direction: 'alternate',
    loop: true
});
// 调用 stop('box') 停止
```

### 实现说明

- 动画在 C++ AnimationEngine 中运行，由主循环每帧 update() 驱动
- 插值结果通过 applyAnimationFrame() 写入视图属性，不触发树重建
- 脏矩形追踪自动覆盖缩放变化的视觉区域
- 弹性缓动可能 overshoot 超过 [0, 1] 范围，插值结果不受限
