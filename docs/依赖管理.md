# 依赖管理

## 结构
- `third_party/`：9 个三方库全部**快照内嵌**（普通文件随主仓 git 分发），零 submodule
- 每库版本/许可/提取规则/补丁登记于 `third_party/README.md`（权威载体）
- 引入入口唯一：`cmake/modules/Dependencies.cmake`（FFmpeg 构建驱动在 `FFmpeg.cmake`，由其 include）
- 我方补丁：主仓普通提交（烤入快照）+ `patches/<lib>/0001-*.patch`（升级重放材料）

## 协作者构建（零网络、零 submodule）
    git clone <仓库>
    cmake --preset gcc              # Debug 树（build/，默认档）
    cmake --build build -j
- 编译档入口 `KWIK_BUILD_TYPE`（Debug/Release/MinSizeRel），configure 阶段定死
  到树缓存；Release 用 `cmake --preset gcc-release`（build-release/ 树）——
  单配置生成器，`--build` 不带 `--config`，档位跟树走
- FFmpeg 视频后端额外需要本机 Git bash + mingw32-make（工具依赖，非网络）；
  缺失时自动降级 Null 播放器，不影响其余功能
- 裁剪开关：`KWIK_ENABLE_VIDEO=OFF`（不编视频）、`KWIK_ENABLE_G3D=OFF`（不编 3D）、
  `KWIK_ENABLE_CHART=OFF`（不编图表）

## SDK 消费（外部工程，find_package）

安装（前缀默认落构建树，`-DCMAKE_INSTALL_PREFIX` 可覆盖）：

    cmake --build build-release -j
    cmake --install build-release        # → build-release/install

外部工程接入（入库样板：`examples/external`；构建 `examples/external/build.bat`）：

    cmake -B build -G Ninja -DCMAKE_PREFIX_PATH=<仓库>/build-release/install \
          -DCMAKE_BUILD_TYPE=Release
    find_package(kwik-ui REQUIRED)          # CMakeLists.txt 内
    kwik_js(<target> ENTRY js/main.js)      # Debug=文件系统热重载 / Release=嵌入字节码

- 反射旗标（`-freflection`/stdc++exp）与链接保序（静态库先于 Vulkan）由包配置
  自动注入，消费者零额外设置
- 版本兼容 `SameMajorVersion`：`find_package(kwik-ui 0.2.3)` 可用，
  版本号随 CHANGELOG 同步（CMakeLists 顶部 project VERSION）

## 升级三方库（维护者 SOP）
1. `scripts/vendor_update.ps1 -Lib <库名> -Ref <tag>`
2. 补丁冲突 → 人工合并 → 更新 `patches/<lib>/*.patch`
3. 更新 `third_party/README.md` 的 Version 行
4. 验证门禁：零警告 build + ctest + smoke 44/44（FFmpeg 升级后删 build/ffmpeg-build 重 configure）
5. 单次 commit：`vendor: <lib> <版本> + 补丁`

对比原理（全量保留模式）：升级 diff = 旧快照 commit ↔ 新快照 commit 的**全量**对比，
`.github/`/`tests/`/`doc/` 等一并入库、参与 diff——测试语料/文档的跨版本变动
属正常噪音，无碍阅读主线变更。例外排除项仅登记于 `third_party/README.md`
（如 fastgltf/deps/ 下载产物）。

## 打补丁纪律
1. 直接改主仓快照文件 → 单独 commit「patch: <原因>」
2. 同步一份 `.patch` 到 `patches/<lib>/`（升级时重放）
3. 能上游化的尽量提 PR，长期持有补丁越少升级越省

## 新增三方依赖流程
1. `vendor_update.ps1` 规则表 + README 登记该库
2. `Dependencies.cmake` 引入（守卫清单同步加名字）
3. 门禁验证 + CHANGELOG
