# 布局系统

KwiK 的布局不是独立引擎，而由一组容器组件共同约定的**尺寸解析与约束传递模型**。
本文承载跨容器的模型层语义（各容器专有属性在其组件篇内）。

## 尺寸解析模型

每个参与布局的组件，`width` / `height` 三态解析（通用 ViewProps，见
[总览](1.kwik-ui%20组件.md)）：

| 写法 | 语义 |
|------|------|
| number | 固定像素尺寸 |
| `"50%"` | 百分比，基准 = **父容器 content 尺寸**（padding 内可用区域） |
| null / 不设 | 自适应（随内容或父约束） |

百分比解析要点（详见 [view.md](components/view.md)）：

- 父容器尺寸**有界**（固定宽/高或 tight 约束）才解析；父为自适应（无界约束）
  时百分比**回退为内容自适应**（CSS 同款，不报错）
- v1 仅支持 View/Flex 自身的 width/height 百分比；**margin/padding 百分比暂不支持**

## 布局容器选型一览

| 容器 | 布局方式 | 子节点来源 | 滚动 | 适用（详见组件篇） |
|------|----------|-----------|------|--------------------|
| [Flex](components/flex.md) | 主轴堆叠 + flexGrow 弹性 + wrap 换行 | children | 无 | 行/列排布、流式布局 |
| [Grid](components/grid.md) | gridRow/gridColumn 网格坐标（可跨行跨列） | children | 无 | 二维网格 |
| [Stack](components/stack.md) | 子项同 Z 层堆叠，靠 position:absolute 精确放置 | children | 无 | 叠加/画布 |
| [List](components/list.md) | 单轴自动堆叠，超容器即滚动 | children（全量） | 内置（无滚动条） | 静态/内容自适应高度列表 |
| [ScrollView](components/scrollview.md) | **不干预子布局**（x/y 自由），裁剪视口按包围盒并集滚动 | children（全量） | 内置（比例滚动条） | 任意可滚内容、双轴大画布 |
| [LazyList](components/lazylist.md) | 虚拟化窗口，仅可视区+overscan 构建 | items + itemBuilder | 内置（v1 无滚动条） | 千/万行大数据集 |

三者滚动分工速记：**List = 自动堆叠 + 单轴滚动；ScrollView = 不干预布局 +
裁剪视口 + 滚动条；LazyList = 虚拟化 + 大数据集**（对比表见
[scrollview.md](components/scrollview.md) / [lazylist.md](components/lazylist.md)）。

## 约束传递与滚动方向

容器的滚动方向决定子节点测量约束的**有界/无界轴**（以
[ScrollView](components/scrollview.md) 为例）：

| direction | 子节点测量约束 |
|-----------|----------------|
| `vertical`（默认） | 宽 = 视口（有界）、高无界 |
| `horizontal` | 高 = 视口（有界）、宽无界 |
| `both` | 双轴无界（大画布） |

由此联动：在"双轴无界"或"无界父"约束内使用 `"50%"` 百分比会回退为
自适应——百分比尺寸只适合放在有界容器（固定尺寸 View/Flex、方向有界轴）内。

Flex 的 `flexWrap: "wrap"` 换行语义（行间 gap、`stretch` 换行时拉伸基准 =
该行行区高度）见 [flex.md](components/flex.md)。

## 层叠与定位

- 定位模型：`position: "relative"`（默认，参与所在容器布局）与
  `"absolute"`（脱离布局，经 top/left/right/bottom 定位，-1=自动，
  另有显式 x/y 偏移）——均属通用 ViewProps[（View 篇）](components/view.md)
- 绘制层级：`z`（默认 0，越大越靠前）在同级间决定前后，不改变命中结构
- [Stack](components/stack.md) 的层叠模型即"子项同 Z 轴堆叠 + absolute
  精确放置"的容器化表达
- 真正"浮在最上层"的内容不属于 View 树层叠，走
  [Layer 统一浮层](components/layer.md)（LayerStack 图层，不被祖先裁剪）

## 滚动契约（跨容器统一行为）

- **滚轮统一路径**：List / ScrollView / LazyList 三者的滚轮事件均经
  事件阶段② `applyScroll` 单次应用——路由 hitTest 后沿父链找第一个
  `scrollable()` 祖先收编（详见 [lazylist.md](components/lazylist.md) 分工注记）
- **滚动条仅 ScrollView 提供**（比例滑块，内容溢出才显示；拖拽 1:1、
  点轨道跳转）；List/LazyList v1 无滚动条
- **水平滚轮**：win32 无水平滚轮，`horizontal` 方向回退用垂直 delta
  （`dx != 0 ? dx : dy`）——见 [scrollview.md](components/scrollview.md)
- **header/footer**：List 与 LazyList 均支持固定头/尾（滚动区外，不随主轴滚动）
- **内容溢出**：[Table](components/table.md) 无内置滚动，内容超宽需自行外包
  Scroll/ListLayout

## 常见坑对照

| 坑 | 根因 | 出口 |
|---|---|---|
| 无界父内 `"50%"` 不生效（变大自适应） | 百分比回退规则 | 父给固定尺寸或换有界轴（view.md） |
| margin/padding 写 `"5%"` 无效果 | v1 不支持其百分比 | 用 px 四元组 |
| 满宽卡片内 textAlign center 看不出偏移 | 未显式 width，文本自适应收紧 | 设 width（含 "50%"）（text.md） |
| Table 行数多显示不全 | 无内置滚动 | 外包 [List](components/list.md)/ScrollView |
| 双轴画布内靠百分比定位内容 | both 双轴无界 | 用 x/y 绝对摆放（scrollview.md） |
