# 当前任务 — 能力缺口与优先级

> 更新时间：2026-08-15

## 一、能力缺口现状（渲染 / 动画 / 文本 / 手势 / 滚动 / 布局）

### 渲染
- **无 rotate / GPU transform**：`transform` 仅 `translateX/Y` 两个字段，全部 CPU 烘烤，
  shader 无 transform uniform → 指针旋转、转场、loading 转圈全做不了
  （当前 Spinner 靠 12 圆点 + cos/sin 硬算位置绕过，非真旋转）
- **无渐变**：全库零命中（按钮/卡片/背景/进度条均无法做渐变）
- **无离屏渲染 / 自定义着色器**：`renderTarget` 零命中（blur / shader 特效做不了）
- **无隐式 transition**：`setPropertyTyped` 直接写死，状态切换无过渡（仅有 `animate()` 显式动画）

### 文本
- `ellipsis` 枚举预留未实现、无 `maxLines`、无垂直对齐、无 emoji/彩色字形、
  `lineHeight` 字段未用、`Justify` 等同 `Left`

### 手势
- Swipe 无（Pan 无 velocity）、DoubleTap/Pinch/Rotate 空壳、无 Tab 焦点遍历

### 滚动
- 无触屏拖拽滚动、无惯性/回弹

### 布局
- 无 `flexWrap`、无百分比尺寸、无 `aspectRatio`、无 `overflow:hidden`（除 ScrollView）

## 二、主要缺失判断

**P0 — GPU transform（含 rotate）**：架构级缺口，且是"预留未兑现"
（`TransformLayer`/`OpacityLayer` 是空壳，坐标/颜色仍 CPU 烘烤，shader 无 transform uniform）。
rotate 无法 CPU 烘烤近似 → 旋转动画/转场/loading 从根上缺失；落地后可带动 rotate、
转场、GPU 加速变换，也是未来离屏渲染/自定义着色器的变换基础。

**P0 — 渐变（linear/radial）**：影响面最大（所有视觉元素高频基础），
实现成本低（复用 `rect.slang` SDF 框架加渐变模式，类比 segment 胶囊）。

**P1 — 隐式 transition**：声明式过渡，动画易用性关键（`setPropertyTyped` → 自动补间）。

**P1 — 文本排版**：`ellipsis/maxLines/lineHeight/垂直对齐` 为日常多行文本基础；
`emoji/彩色字形` 为进阶。

**P2 — 离屏渲染 / 自定义着色器**：进阶能力（blur/shader），等 P0 transform 落地后更顺。

**P2 — 手势 / 滚动 / 布局**：移动端体验，桌面端影响小。
