# 当前任务 — 能力状态与下一步

> 更新时间：2026-08-16

## 一、已完成能力（均带 demo 验证）

- 渲染：GPU transform/rotate、背景渐变（linear/radial）、隐式 transition
- 布局：flexWrap 多行换行、百分比尺寸（width/height "50%"）
- 文本：wordWrap / maxLines+省略号 / lineHeight / verticalAlign / 两端对齐，
  Text 背景/padding/百分比宽渲染、Text 排版属性增量绑定（ref）、TextArea reconcile 补齐
- 组件库：40+ 组件与 demo（Chart/DatePicker/Tabs/TreeMenu/LazyList 等）

## 二、下一步候选（按优先级）

1. **手势/滚动增强**：ScrollView 内容拖拽 + 惯性回弹、Swipe / Pan velocity
   —— 中等工作量，桌面可用鼠标验证
2. **离屏渲染/自定义着色器**：renderTarget/FrameBuffer → blur / 自定义 shader 特效
   —— 工作量大，transform 已落地、条件成熟
3. **布局补全**：aspectRatio、overflow:hidden、Grid/List/ScrollView 容器自身百分比
   —— 小而稳
4. **文本进阶**：emoji / 彩色字形渲染 —— 中等工作量

## 三、已知小缺陷

- TextArea 增量绑定仅覆盖 value/fontSize/rows（缺 color/placeholder 等）
- 滚动仅滚轮 + 滚动条滑块，无内容拖拽 / 惯性回弹
- 省略号依赖字体含 U+2026 字形
