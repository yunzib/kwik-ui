# Grid — 网格布局

子项通过 gridRow/gridColumn 指定网格位置，支持跨行跨列。

## 专有属性

```json
{
    "columns": "number",               // 列数 (默认 1)
    "rows": "number",                  // 行数 (默认 1)
    "columnGap": "number",             // 列间距 px (默认 0)
    "rowGap": "number"                 // 行间距 px (默认 0)
}
```
