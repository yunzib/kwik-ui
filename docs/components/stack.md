# Stack — 堆叠布局

所有子项在相同 Z 轴层级堆叠，通过 position: "absolute"
配合 top/left/right/bottom 实现任意位置精确定位。

## 专有属性

**无专有属性** —— 定位依赖[通用 ViewProps](view.md)的
`position: "absolute"` 配合 `top/left/right/bottom`。
