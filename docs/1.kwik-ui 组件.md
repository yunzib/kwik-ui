# 1. 组件总览

KwiK UI 内置 32 组件 + 扩展组件（Video / G3D）。本文是**组件体系总览**：继承模型
与组件索引。**每个组件的完整明细（专有属性表 /
行为语义 / 示例 / demo）在 [components/](components/) 目录下一组件一文**，
文件名即组件 id。

- 明细篇模板：frontmatter（group / status / docsite 同步状态）+ 简介 +
  专有属性 + 语义小节 + 示例 + 关联
- 布局类容器的**跨组件模型语义**（尺寸解析 / 约束传递 / 滚动契约）集中见
  [7. 布局系统](7.%20布局系统.md)

## 通用属性

所有组件继承**通用 ViewProps**（width 三态 / padding / opacity / transform /
liquid glass / 事件与生命周期回调……）。完整属性表与数据类型格式收在
[View 篇](components/view.md#通用属性viewprops)——View 为通用属性完备实例；
transform / gradient / 过渡补间 / 百分比尺寸 / 液态玻璃的**深化语义**也在
该篇对应小节。布局容器对尺寸模型的整体约定见 [7. 布局系统](7.%20布局系统.md)。
