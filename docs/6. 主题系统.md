# 主题系统

KwiK UI 使用 Material Design 3 风格的 token 化主题系统。通过 `theme()` 函数定义色值，
`<ThemeProvider>` 注入子树，组件通过 `@` 前缀引用主题 token。

```json
{
    "type": "ThemeProvider",
    "props": {
        "theme": "theme({...})",           // 主题数据（必需）
        "mode": "\"light\" | \"dark\"",    // 明亮/暗黑模式（默认 "light"）
        "colors": {
            "primary": "\"#1976D2\"",      // 主色
            "onPrimary": "\"#FFFFFF\"",     // 主色上的内容色
            "surface": "\"#FFFFFF\"",       // 表面色
            "onSurface": "\"#1C1C1E\"",     // 表面上的内容色
            "surfaceVariant": "\"#F5F5F5\"",
            "onSurfaceVariant": "\"#6E6E72\"",
            "error": "\"#D32F2F\"",
            "onError": "\"#FFFFFF\"",
            "outline": "\"#C4C4C6\"",
            "divider": "\"#E0E0E0\"",
            "disabled": "\"#E0E0E0\"",
            "disabledText": "\"#A0A0A0\""
        },
        "shape": {
            "borderRadius": "number"       // 全局圆角（默认 0）
        }
    },
    "children": [...]                      // 子树
}
```
### 颜色引用

所有颜色属性均支持 `@` prefix 引用主题色值：

| 写法 | 含义 |
|------|------|
| `"@primary"` | 引用主题 primary 色值 |
| `"#FF0000"` | 直接使用 hex 色值（不经过主题） |
| `"transparent"` | 透明 |
| `"@onPrimary"` | 引用主题 onPrimary 色值 |

### 颜色 token 表

| token | 亮色默认 | 暗色默认 | 用途 |
|-------|---------|---------|------|
| `primary` | `#1976D2` | `#A5B4FC` | 主色 — Button 背景、Input 聚焦边框 |
| `onPrimary` | `#FFFFFF` | `#000000` | 主色上的内容 — Button 文字 |
| `surface` | `#FFFFFF` | `#1C1C1E` | 表面色 — 卡片/弹窗背景 |
| `onSurface` | `#1C1C1E` | `#E5E5EA` | 表面上的内容 — 正文文字 |
| `surfaceVariant` | `#F5F5F5` | `#2C2C2E` | 表面变体 — 分割行/次级背景 |
| `onSurfaceVariant` | `#6E6E72` | `#98989D` | 表面变体上的内容 — 占位文字 |
| `error` | `#D32F2F` | `#FF453A` | 错误色 |
| `onError` | `#FFFFFF` | `#FFFFFF` | 错误色上的内容 |
| `outline` | `#C4C4C6` | `#48484A` | 轮廓色 — 边框/分割线 |
| `divider` | `#E0E0E0` | `#38383A` | 分割线色 — List 分隔线 |
| `disabled` | `#E0E0E0` | `#38383A` | 禁用背景 |
| `disabledText` | `#A0A0A0` | `#606060` | 禁用文字 |

### 使用示例

```js
const darkTheme = theme({
    mode: "dark",
    colors: {
        primary: "#A5B4FC",
        onPrimary: "#FFFFFF"
    },
    shape: { borderRadius: 12 }
});

View(
    { id: "root" },
    ThemeProvider({
        theme: darkTheme,
        children: [
            Button({
                text: "Filled",
                background: "@primary",
                color: "@onPrimary",
                borderRadius: "@borderRadius"
            })
        ]
    })
)
```
实现说明
- ThemeProvider 不产生绘制内容，仅作为主题数据注入节点
- 子组件在 layout 阶段调用 resolveThemeDefaults() 解析 @ token
- 主题沿 View 树自顶向下传递，子树内嵌套的 ThemeProvider 会覆盖上层主题
- 未设置主题时使用亮色模式默认值，只传部分色值时其余保留默认值
