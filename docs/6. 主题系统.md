# 主题系统

KwiK UI 使用 Material Design 3 风格的 token 化主题系统。通过 `theme()` 函数定义色值，
`<ThemeProvider>` 注入子树，组件通过 `@` 前缀引用主题 token。

```json
{
    "type": "ThemeProvider",
    "props": {
        "theme": "theme({...})"            // 主题数据（必需；运行时可换值，见「运行时切换」）
    },
    "children": [...]                      // 子树（测量/布局按 View 纵向流）
}
```

`theme(options)` 选项（未传字段保留基底值）：

```json
{
    "mode": "\"light\" | \"dark\"",        // 基底：亮色默认 / 暗色基底（默认 "light"）
    "colors": {                            // 覆盖任意 token，值为 "#rrggbb"
        "primary": "\"#1976D2\"",
        "onSurface": "\"#1E293B\""
    },
    "text": {                              // 三级字号/字重
        "heading": { "size": 24, "weight": "\"bold\"" },
        "body":    { "size": 16, "weight": "\"normal\"" },
        "caption": { "size": 12, "weight": "\"normal\"" }
    },
    "shape": {
        "borderRadius": "number"           // 全局圆角（默认 6）
    }
}
```

### 颜色引用

| 写法 | 含义 |
|------|------|
| `"@primary"` | 引用主题 primary 色值 |
| `"#FF0000"` | 直接使用 hex 色值（不经过主题） |
| `"transparent"` | 透明 |
| `"@borderRadius"` | 圆角属性引用 shape.borderRadius（等价 `"@shape.borderRadius"`） |

可写 `@token` 的属性：

- 通用：任意组件的 `background` / `borderColor` / `borderRadius`（View、Flex 等容器亦然）
- 组件专有颜色属性：Text `color`、Button `color`，以及 Input / Checkbox / Switch /
  RadioButton / Slider / ProgressBar / Spinner / Tabs / Chart / Dropdown /
  DateTimePicker / TextView / SpinBox 的颜色属性（见各组件文档）
- 未列入的颜色属性不解析 `@token`（按字面色处理）

### 颜色 token 表

| token | 亮色默认 | 暗色基底 | 用途 |
|-------|---------|---------|------|
| `primary` | `#1976D2` | `#90CAF9` | 主色 — Button 背景、Input 聚焦边框 |
| `onPrimary` | `#FFFFFF` | `#0D0D17` | 主色上的内容 — Button 文字 |
| `surface` | `#FFFFFF` | `#1E1E2E` | 表面色 — 卡片/弹窗/Input 背景 |
| `onSurface` | `#1E293B` | `#CDD6F4` | 表面上的内容 — 正文文字 |
| `surfaceVariant` | `#F8FAFC` | `#313244` | 表面变体 — 分割行/次级背景 |
| `onSurfaceVariant` | `#64748B` | `#A6ADC8` | 表面变体上的内容 — 占位文字 |
| `error` | `#D32F2F` | `#D32F2F` | 错误色 |
| `onError` | `#FFFFFF` | `#FFFFFF` | 错误色上的内容 |
| `outline` | `#CBD5E1` | `#45475A` | 轮廓色 — 输入框边框 |
| `divider` | `#E2E8F0` | `#313244` | 分割线色 — List 分隔线 |
| `disabled` | `#F1F5F9` | `#313244` | 禁用背景 |
| `disabledText` | `#94A3B8` | `#585B70` | 禁用文字 |

### 使用示例

```js
const darkTheme = theme({
    mode: "dark",
    colors: {
        primary: "#A5B4FC",
        onPrimary: "#FFFFFF"
    },
    shape: { borderRadius: 12 }
});

View({ id: "root" }, [
    ThemeProvider({ theme: darkTheme }, [
        Button({
            text: "Filled",
            background: "@primary",
            color: "@onPrimary",
            borderRadius: "@borderRadius"
        })
    ])
])
```

### 运行时切换

`theme` 值换成另一个主题对象即完成换肤，由 State 驱动：

```js
const lightTheme = theme({ mode: "light" });
const darkTheme  = theme({ mode: "dark" });
const ui = new State({ mode: "light" });

export default () => Root(
    ThemeProvider({ theme: ui.mode === "dark" ? darkTheme : lightTheme }, [
        View({ background: "@surface", borderColor: "@outline", borderWidth: 1, padding: 16 }, [
            Text({ text: "正文", color: "@onSurface" }),
            Button({ text: "切换主题", background: "@primary", color: "@onPrimary",
                     onClick: () => { ui.mode = ui.mode === "dark" ? "light" : "dark"; } }),
        ]),
    ])
);
```

- ThemeProvider 原位复用并替换主题数据（逐字段判等，同值零动作）
- 子树 `@token` 按新主题重解析——节点不重建，输入内容、滚动位置、焦点等运行态保留
- 主题对象作模块级常量复用；勿在渲染函数内每次 `theme({...})` 新建
- 文档站顶栏「暗色 / 亮色」按钮即此用法（test/docsite/js/ui/app_theme.js）

实现说明
- ThemeProvider 不产生绘制内容，仅作为主题数据注入节点
- 树构建与 reconcile 时调用 resolveThemeDefaults() 解析 @ token（父链挂接后上溯最近 Provider）
- 主题沿 View 树自顶向下传递，子树内嵌套的 ThemeProvider 会覆盖上层主题
- 未设置主题时使用亮色默认值，只传部分色值时其余保留基底值
